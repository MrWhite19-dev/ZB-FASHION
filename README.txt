ZB FASHION — Site vitrine + e-commerce de démonstration
Fichiers :
- index.html : accueil
- boutique.html : catalogue, filtres, panier local et commande WhatsApp
- salon.html : présentation salon homme et formulaire de demande de rendez-vous WhatsApp
- css/style.css : styles responsive
- js/script.js : menu mobile, panier et formulaires
- js/products.js : produits de démonstration

Pour tester :
1. Extraire le dossier.
2. Ouvrir index.html dans un navigateur.
3. Pour de meilleurs résultats, ouvrir le dossier dans VS Code et utiliser Live Server.

IMPORTANT :
- Le numéro WhatsApp est configuré en format international Côte d'Ivoire : 2250777087409.
- Les prix, photos, produits, services et horaires sont des exemples de démonstration à valider avec l'entreprise.
- Les commandes et rendez-vous ouvrent WhatsApp. Aucun paiement en ligne ni confirmation automatique n'est configuré.
- Les photos sont chargées depuis Unsplash : une connexion Internet est nécessaire pour les afficher.
